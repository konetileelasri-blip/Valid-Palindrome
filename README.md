 Valid Palindrome

📌 Problem

Given a string "s", determine whether it is a palindrome.

Only alphanumeric characters are considered, and uppercase and lowercase letters are treated as the same.

💡 Example

Input: s = "A man, a plan, a canal: Panama"

Output: true

Input: s = "race a car"

Output: false

💻 Language

Java

📂 File

"ValidPalindrome.java"

🧠 Approach

1. Use two pointers: "left" and "right".
2. Ignore spaces and special characters.
3. Compare characters from both ends.
4. Convert characters to lowercase before comparing.
5. Move the pointers toward the center.
6. If all characters match, return "true".

⏱️ Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)

🎯 Goal

To practice strings and the two-pointer technique in Java.
